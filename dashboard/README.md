# داشبورد دانش پروژه

تجمیع کل دانش مخزن در یک صفحه‌ی ایستا: حقایق EDA، یافته‌ها، تصمیم‌ها، فیچرها، مقایسه‌ی
مدل‌ها، ارزیابی، تفسیرپذیری، لایه‌ی تصمیم، گالری شکل‌ها و نقشه‌ی اسناد.

داشبورد **منبع حقیقت نیست** — خواننده‌ی منابع موجود است. هر عدد از `doc/` یا `reports/`
می‌آید و مسیر فایل شاهدش کنارش نوشته شده. اگر عددی اینجا غلط بود، فایل شاهد را درست
کنید و دوباره build بگیرید، نه این داشبورد را.

## اجرا

```bash
python dashboard/build.py
```

بعد `dashboard/index.html` را در مرورگر باز کنید (دابل‌کلیک کافی است — هیچ وابستگی
بیرونی، CDN یا سرور لازم نیست). اگر ترجیح می‌دهید سرو شود:

```bash
python -m http.server 8777
```

و بروید به `http://127.0.0.1:8777/dashboard/`.

## ساختار

| مسیر | نقش |
|---|---|
| `build.py` | استخراج‌گر: مخزن را می‌خواند و `data/dashboard-data.js` را می‌سازد |
| `index.html` | پوسته‌ی صفحه (راست‌به‌چپ، `lang="fa"`) |
| `assets/app.js` | رندر پنل‌ها، فیلتر، مرتب‌سازی، نمودارها، جست‌وجوی سراسری |
| `assets/style.css` | سبک پایه، تم روشن/تیره |
| `assets/fonts/` | وزیرمتن (SIL OFL) — تعبیه‌شده تا آفلاین هم درست رندر شود |
| `data/dashboard-data.js` | خروجی تولیدشده؛ **دستی ویرایش نشود** |
| `figures` | symlink به `../reports/figures` — شکل‌ها کپی نمی‌شوند |

## میان‌بُرها

- `Ctrl+K` یا `/` — جست‌وجوی سراسری روی همه‌ی بخش‌ها
- `↑` `↓` و `Enter` — پیمایش نتایج جست‌وجو
- `Esc` — بستن جست‌وجو یا بزرگ‌نمایی شکل

## نکته‌های استخراج

سه جای منبع به رفتار خاص نیاز داشت و در `build.py` صریح مدیریت شده است:

1. **`F54`** در دفتر حقایق ردیف جدول نیست، بلوک نقل‌قول است. بدون پاس دوم از داشبورد
   غایب می‌ماند، پس با فلگ `calloutOnly` جدا خوانده می‌شود.
2. **ردیف ۶۲ `decision_log`** دو تصمیم کاملاً متفاوت با یک شماره است. چون ردیف‌های این
   دفترچه از جاهای دیگر مخزن با شماره ارجاع داده شده‌اند، شماره عوض نمی‌شود؛ مثل قاعده‌ی
   خودِ `findings_register` برای شناسه‌های ۲۸ و ۲۹، پسوند `الف`/`ب` می‌گیرند و برخورد
   در بخش «نمای کلی» به‌عنوان هشدار کیفیت داده نمایش داده می‌شود.
3. **لاتک درون‌خطی** (`$\tau$`, `$C_o$`, `$(d,m,r,f)$`) رندر نمی‌شود؛ نمادهای پرتکرار به
   یونیکد تبدیل می‌شوند (`τ`, `C₀`, `(d,m,r,f)`).

## پس از تغییر مخزن

`build.py` را دوباره اجرا کنید. هر تغییری در `doc/` یا `reports/` — ردیف جدید در
`decision_log`، حقیقت تازه، شکل جدید، تیک‌خوردن یک بسته‌ی کاری — با همان یک دستور به
داشبورد می‌آید. هیچ عددی در `index.html` یا `app.js` دستی نوشته نشده.
