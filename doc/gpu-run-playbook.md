## چه چیزی داخل هر بسته‌ی برگشتی هست

| مسیر | محتوا |
|---|---|
| `mlruns_gpu/` | هر trial + یک run `stage=S3` به‌ازای هر قهرمان، با artifact مدل ضمیمه |
| `models/gpu/<family>/<model>/` | وزن + پیش‌پردازش هر (fold × seed) — با `FITTERS[...].load(stem)` قابل بازاستفاده |
| `reports/gpu/*.md` | گزارش فارسی کامل: R0، R2، قهرمان، پراکندگی seed، ACI، DM |
| `reports/gpu/*.json` | همان اعداد به‌صورت ماشین‌خوان (ورودی `card_writer`) |
| `reports/gpu/*.csv` | جدول‌های اختصاصی هر خانواده (کرنل، ARD، PPC، حساسیت پیشین، تجمیع) |
| `optuna_studies/*.db` | مطالعه‌ی کامل — برای fANOVA اهمیت هایپرپارامتر (گام ۱۰ کارت مدل) |

**مدل ذخیره‌شده واقعاً قابل استفاده است**، نه فقط یک فایل: هر نوت‌بوک یک سلول
«راستی‌آزمایی» دارد که مدل را از دیسک برمی‌گرداند و دوباره پیش‌بینی می‌گیرد. برای
مدل‌های بیزی و GP، این یعنی می‌شود بدون هیچ نمونه‌گیری/برازش دوباره، برای **هر τ**
پیش‌بینی گرفت.

  مگابایتی. چهار تست جدید در `src/models/tests.py` (جمعاً ۳۲ تست، همه PASS).
- ✅ **آزموده شد:** ثبت هر ۹ مدل GPU در رجیستری + نمونه‌گیری از فضای
  هایپرپارامترشان با Optuna، و اینکه هیچ خانواده‌ی GPU در سطح ماژول

- ✅ **آزموده شد:** بسته‌ی آپلود به‌صورت مستقل (خارج از مخزن) باز می‌شود، دروازه‌ی
